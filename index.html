Adaptive SQL, Python, R and SAS practice

Claude checking for SAS, and new problems

SQL, Python and R answers are checked by running your code in this browser. SAS can't run in a browser, so by default you compare your answer with the solution yourself. Add an Anthropic API key to let Claude read your SAS (and any R or Python that can't run here), predict its output and grade it, and to write new problems when a skill runs out.

The key is saved in this browser's local storage and sent only to api.anthropic.com. Requests use Claude Opus 5.5 and are billed to your Anthropic account. Get a key at console.anthropic.com.
